NLP-модуль для Telegram-бота «ДЕЛУ.ВРЕМЯ»

Модуль извлечения договорённостей и параметров событий (интент, тема, дата, время, длительность, периодичность RRULE, место, участники) из сообщений и диалогов на русском языке.

Архитектура и стек
Модель: RAGU-lm (HuggingFace Transformers)
Гибридный пайплайн: LLM отвечает за семантику (intent, тема, место, участники), а регулярные выражения re и dateparser - за точный расчёт дат, сдвигов времени и генерацию правил повторения (RRULE).
Валидация и оценка качества: Pydantic для проверки структуры ответа (JSON), встроенный --selftest и скрипт сквозной оценки на диалогах (evaluate_nlp_cases).
